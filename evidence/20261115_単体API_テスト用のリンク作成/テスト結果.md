作った理由：画面のテスト（Playwright）が、S-03・S-04 などで、パスワード設定用のリンクの合言葉を用意するため。DM と「同じメールアドレスへの依頼は5分に1回」の決まり（A-04）を経由すると、同じ PC で5分以内にテストをやり直したときに、DM が送られず、テストが失敗するため（`bootRun` のテスト設定では、データベースを作り直さない）。`app.test-support.enabled` が true のときだけ動く（Slack の読み出し API と同じ。詳細設計 common.md 3.14）。

詳しいレポートは report/index.html。元の記録は results フォルダ。

## テストの一覧（今回足した8件）

### common.passwordlink.PasswordLinkTestSupportApiTest（8件・失敗0件）

テストの設定（app.test-support.enabled が true）

- 再設定のリンクを作り、合言葉（43文字）を返す。保存するのはハッシュで、A-05 で使える。ログインなし・CSRFの合言葉なしで呼べる
- ロック・ユーザ登録の用途でも作れる。5分に1回の決まりに当たらず、何度でも作れる（前のリンクは無効になる）
- メールアドレスの大文字・小文字は区別しない
- 登録のないメールアドレス・削除されたユーザ：404
- 用途がない・知らない値、メールアドレスが空：400
- DELETE で、リンクが全部消える。ログインなし・CSRFの合言葉なしで呼べる

本番の設定（app.test-support.enabled が false）

- controller と Service の Bean がない
- POST・DELETE とも 404（ログインなしでも、401 ではなく 404）
