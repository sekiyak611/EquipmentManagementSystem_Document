確かめたこと（詳細設計 auth/A-06_合言葉でパスワードを決める.md、common.md 3.15）：

- 再設定・ロック・ユーザ登録のリンクで、新しいパスワードを決められる。新しいパスワードでログインでき、古いパスワードではできない。パスワードは bcrypt のハッシュで保存し、リンクは使用済みになる。
- ロックを解除し、失敗の回数を0に戻す。ロックの流れ全体（5回間違えてロック → DM（③）のリンクで決める → ログインできる）も確かめた。
- 自動ではログインさせない（セッションを渡さない）。前にログインしていた端末は次の操作で 401、決めた直後のログインは使える。session_valid_after は秒までにそろえて入り、updated_by は本人、version は増えない。
- DM（④）を本人に送る（パスワード・合言葉は書かない）。ユーザ登録のリンク（REGISTER）のときは送らない。送れなくても（USER_NOT_FOUND・FAILED）、パスワードは変わり、200 のまま。
- 使えない合言葉（ない・空・使用済み・より新しいリンクがある・期限切れ・削除されたユーザ）は、同じ 400・同じ文で、パスワードは変わらない。同じリンクの2回目も 400。
- パスワードの決まり（画面設計 8章）：空・使えない文字・8文字未満・64文字超は、1つの欄に1つだけメッセージ。境界値（7／8文字、64／65文字）。スペースは前後も取らずに使える。確認が違う・空・ないときは passwordConfirm に「確認用のパスワードが一致しません」。よく使われるパスワード・自分のメールアドレス・システム名（大文字・小文字は区別しない）は 400（password）で、断られたときはリンクを使用済みにしない。
- 同じリンクが4件同時に使われても、成功は1件だけで、反映されるパスワードも1つだけ（`used_at IS NULL` の条件を一時的に外すと、このテストが失敗することも確かめた）。DM も1通。

詳しいレポートは report/index.html。元の記録は results フォルダ。

## テストの一覧（今回足した41件）

### api.auth.passwordtokens.use.AuthPasswordTokensUseApiTest（23件・失敗0件）

- 再設定のリンクで決める：200（data は null）。新しいパスワードでログインでき、古いパスワードではできない
- パスワードそのものは保存しない（bcrypt のハッシュ）。リンクは使用済み（used_at）になる
- ロックを解除し、失敗の回数を0に戻す
- ロックの流れ全体：5回間違えてロック → DM（③）のリンクで決める → ロックが解け、ログインできる
- 自動ではログインさせない：ログイン状態（セッション）を渡さない
- すべての端末のログインを切る：前にログインしていた端末は、次の操作で 401。決めたあとのログインは使える
- session_valid_after には、今を秒までにそろえて入る。updated_by は本人、version は増えない
- 再設定：パスワードが変わったことを、本人にDM（④）で知らせる。パスワードは書かない
- ユーザ登録のリンク（REGISTER）：パスワードがまだない人が、最初のパスワードを決められる。DMは送らない
- ロックのリンク（LOCK）でも決められる。DM（④）は送る
- ログインしていなくても呼べる
- 同じリンクを2回使えない：2回目は 400（使えないリンク）。パスワードは1回目のまま
- 使えない合言葉（ない・空・ない値・より新しいリンクがある・期限切れ・削除されたユーザ）：400。同じ文。パスワードは変わらない
- 使えないパスワード（よく使われる）：400。password に画面設計 8章の文。リンクは使用済みにならず、別のパスワードで決め直せる
- 使えないパスワード：大文字・小文字がちがっても、自分のメールアドレス・システム名は使えない
- 入力の誤り：空は 400。errors は password の1件だけ（確認も空なら一致する）
- 入力の誤り：7文字は短い、65文字は長い、日本語は使えない文字。どれも1つだけ
- 64文字のパスワードで決められ、そのパスワードでログインできる
- スペースを含むパスワードは、前後も取らずに、そのまま決められる
- 入力の誤り：確認が違う・空・ないときは、passwordConfirm に「確認用のパスワードが一致しません」
- 入力の誤り：パスワードの形と確認の違いが同時にあれば、2つとも errors に出る
- 入力の誤りが先：パスワードが誤りで、合言葉も使えないときは、入力の誤り（400・errors あり）を返す
- なりすまし対策の合言葉（CSRF）がなければ 403
