確かめたこと（詳細設計 auth/A-05_合言葉の確認.md、common.md 3.14）：

- 使える合言葉：200。data に対象のメールアドレスと用途（RESET・LOCK・REGISTER）。
- 使えない合言葉（ない・空・使用済み・より新しいリンクが作られた・期限切れ・削除されたユーザ）：どれも同じ 400・同じ文「このリンクは使えません。有効期限が切れたか、すでに使われています。」。errors は null。期限切れの境界は、期限の1秒後は使えず、1分前なら使える。
- 開いただけでは、使用済みにしない。何度確かめても同じ答えで、used_at・revoked_at は空のまま（何も書き換えない）。
- ログインなしで呼べる。CSRF の合言葉がなければ 403。

詳しいレポートは report/index.html。元の記録は results フォルダ。
画面の証跡は残していない（Client は変えていない）。
