## 見つかったこと（既存のコード）

1. **`LoginRememberMe` が Clock を使っていなかった**（`System.currentTimeMillis()`。ZPOP-125 で作ったもの）。Clock を受け取る形に直した。remember-me の Server のテスト（30件）と Client の画面テストは、直したあとも成功。
2. **record が4か所にある**（common.error.ApiResponse・ErrorItem、common.security.LoginUser、common.config.AppProperties）。CLAUDE.md 3章の「record は使わない」に合わない。直すと影響が大きいので、例外として ArchitectureTest に書いた（増やさない）。普通のクラスに直すかは、人が決める。
3. **`@PreAuthorize` がない API が5つ**（ログイン・パスワードの再設定の依頼・合言葉の確認・合言葉で決める・死活の確認）。どれもログイン不要の API（SecurityConfig の permitAll）なので、一覧にして例外にした。
