## テストの一覧（今回足した49件。スマートフォン・PC それぞれで動かす）

- 借りている備品がなければ、「借りている備品はありません。」と「＋ 備品を借りる」だけが出る（本物の Server）
- 催促の日時の前：未確認の件数と「11/25（水）9:00 までに確認してください。」が出て、まとめてのボタンに件数が出る
- 催促の日時を過ぎたら、「あります。確認してください。」と出る
- すべて確認済みなら、「今月の確認はすべて済んでいます。」が出て、まとめてのボタンは出ない。「確認済み」は押せない
- 備品1件：管理番号・種別・メーカー・モデル・日付・状態が出る。返却予定日がなければ「―」。並びは API が返した順のまま
- 返却予定日を過ぎた備品は、返却予定日が赤字になる（過ぎていない備品は赤字でない）
- メーカーとモデルがなければ、その行を出さない。片方だけなら、その方だけを出す
- 長い管理番号・モデル名でも、画面が横にスクロールしない
- 「＋ 備品を借りる」を押すと /borrow に移る
- 並びは API が返した順のまま、画面では並べ直さない（確認済みが先でも、貸出日が新しい順でも、そのまま）
- 催促の日時の形：月・日は0を付けず、時刻は H:mm（12/4（金）9:30）
- スマートフォンでは「まとめて確認した」「＋ 備品を借りる」が横いっぱいで、PC では並べ方が違う。ボタンの高さは44px以上
- 「確認済み」は緑、「未確認」は黄。案内は、未確認があれば黄、すべて済んでいれば緑
- 「確認した」：確認のダイアログは出ず、その備品の ID だけを送り、「確認しました（A001）」が出て、一覧が変わる
- 「まとめて確認した」：確認のダイアログ。「キャンセル」なら何も送らない
- 「まとめて確認した」：確認すると、未確認の備品すべての ID を送り、「2件の備品を確認しました」が出る
- 二重押し：送っている間は、一覧のすべての操作ボタンが押せず、押し直しても送らない。終わると押せる
- 「まとめて確認した」の確認のダイアログ：送っている間は実行ボタンが押せない。窓の外・Esc でも閉じられ、何も送らない
- 帯：次の操作を始めると、前の帯（赤）が消える
- 「返す」のダイアログ：返す備品と今日の返却日（日本時間）が出て、メモは空
- 「キャンセル」で閉じ、入力したメモは捨てられる（開き直すと空）。何も送らない
- 返す：貸出履歴の ID とメモを送り、「返却しました（A001）」が出て、返した備品は一覧から消える（返却日は送らない）
- メモが空（空白だけ）なら、null を送る
- 最後の1件を返すと、一覧は「借りている備品はありません。」になる
- メモ：200文字ちょうどは通り（前後の空白を除いて数える）、201文字だと文が出て送らない。入力を変えると文は消える
- サーバーが「メモの誤り」（400・field が memo）を返したら、ダイアログを開いたまま、メモ欄の下に出す
- 送っている間は、「返す」「キャンセル」が押せず、窓の外・Esc でも閉じない。終わると閉じて、緑の帯が出る
- キャンセル以外の閉じ方：窓の外・Esc でも閉じ、何も送らない
- 長い備品名でも、ダイアログが横にあふれない
- 返す 409（すでに返却されている）：赤の帯を出してダイアログを閉じ、読み直す間は一覧を隠し、最新の一覧を出す
- 返す 403（ほかの人が借りている）：赤の帯。一覧はそのまま（読み直さない）
- 返す 400（備品が管理中でなくなった）：赤の帯を出して、一覧を最新にする
- 返す 404（貸出履歴が取り消された）：「対象が見つかりません。」を赤の帯に出して、一覧を最新にする
- 返す 500：赤の帯。ダイアログを閉じ、一覧はそのまま
- 確認 403（借りていない備品が含まれている）：赤の帯を出して、一覧を最新にする
- 確認 400（管理中でなくなった備品）：赤の帯を出して、一覧を最新にする
- 確認 404（備品がない）：S-19 には移らず、「対象が見つかりません。」を赤の帯に出して、一覧を最新にする
- 確認 500：赤の帯。一覧はそのまま
- 画面を開いて一覧を読むのに失敗したら、帯ではなく S-19（システムの不具合）を出す
- 操作のあとの読み直しに失敗したら、S-19 を出す
- 返す 403（権限項目がない）：赤の帯。ダイアログを閉じ、一覧はそのまま
- 確認 403（権限項目がない）：一覧を読み直し、その読み直しが 403 になって S-19（権限がない）が出る
- 返す 400（errors がない・field が memo でない）：サーバーの文を赤の帯に出して、一覧を最新にする。メモ欄の下には出さない
- 確認 400（errors がない。備品の指定が空など）：サーバーの文を赤の帯に出して、一覧を最新にする
- つながらないとき：画面設計の「問題が発生しました。…」を赤の帯に出す。一覧はそのまま
- メニューに「自分の備品」が出て、押すと S-05 が開く（本物のログイン）
- 「備品を借りる・返す（自分）」を持たない人には、権限がない文を出し、一覧（B-01）は読まない
- 確認の権限（CONFIRM_SELF）を持たない人には、「確認した」「確認済み」「まとめて確認した」を出さない。「返す」は出る
- 「備品を借りる・返す（自分）」を持たない人には、メニューに「自分の備品」が出ない
