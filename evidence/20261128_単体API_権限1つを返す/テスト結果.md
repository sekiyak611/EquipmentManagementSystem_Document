## テストの一覧

### RoleSearchItemDetailsApiTest（15件・失敗0件）

- 総務の権限：200。data は id・name・permissionCodes・version の4項目。権限項目は18件すべて、並び順（sort_order）どおり
- 一般社員の権限：LOAN_SELF と CONFIRM_SELF の2件だけ（ほかの権限の項目が混ざらない）
- 権限項目は、入れた順や名前の順ではなく、並び順（sort_order）で返す
- 権限項目が0件の権限：200。permissionCodes は null ではなく空の配列
- version は、権限の今の version（H-04 で送り返す番号）
- PERMISSION_VIEW だけを持つ人：200
- PERMISSION_MANAGE だけを持つ人：200（どちらか1つあれば呼べる）
- PERMISSION_VIEW・PERMISSION_MANAGE のどちらもない人：403（この操作を行う権限がありません。）。data・errors は null
- ログインしていなければ 401（ログインしてください。）。data・errors は null
- ない権限：404（対象が見つかりません。）。data・errors は null
- 削除済みの権限：404（権限項目が残っていても返さない）。同じ名前で作り直した権限は、別のものとして返せる
- パスの id が数でない：400（入力内容に誤りがあります。）
- 権限がない人が id に文字を入れた：403 ではなく 400（引数の変換が、権限の確認より先に起きる。H-02 の9章の順番）
- ログインしていない人が id に文字を入れた：400 ではなく 401（ログインの確認が先。H-02 の9章の順番）
- 読むだけ：呼んでも、権限・権限項目の対応の中身は変わらない
