画面の絵（画面の配置を文字で表したもの）は、スマートフォンで見たときの縦の並びを表す。PCでは、同じ並びのまま画面の中央に表示する。

## 1. 全画面に共通すること

### 1.1 ヘッダー（画面上部の帯）

| 部品 | 内容 |
|---|---|
| システム名 | 「備品管理」。押すと、ログイン後の最初の画面（機能一覧F-01）に戻る |
| メニュー | スマートフォンでは「≡」ボタンで開く。PCでは横に並べる。その人の権限で開ける画面だけを出す |
| ログイン中の人 | 氏名を表示する。押すと「パスワード変更」と「ログアウト」を出す |

ログイン前の画面（S-01〜S-03）には、システム名だけを表示する。

### 1.2 メッセージの出し方

| 種類 | 出し方 | 例 |
|---|---|---|
| 完了 | 画面の上に緑の帯で出し、5秒で消える | 「借りました（A001）」 |
| 入力の誤り | 誤りのある入力欄のすぐ下に赤字で出す | 「メールアドレスを入力してください」 |
| 操作できなかった | 画面の上に赤の帯で出し、自分で閉じるまで残す | 「この備品はすでに貸し出されています」 |

### 1.3 表示の決まり

| 対象 | 決まり |
|---|---|
| 日付 | 2026/11/02 の形。曜日が要る所は 2026/11/02（月） |
| 空の値 | 「―」を表示する |
| 二重押し | ボタンを押したら、処理が終わるまでそのボタンを押せなくする（同じ登録が2回されないように） |
| 確認のダイアログ | ダイアログ＝画面を移らずにその場で開く小さな入力窓。「キャンセル」か、窓の外を押すと閉じる |

### 1.4 ログインしていないとき

ログインが必要な画面を開くと、S-01に移る。ログインしたあとは、最初に開こうとした画面に移る（SlackのDMのリンクからS-05を開いた場合など）。

## 2. S-01 ログイン

**目的**：メールアドレスとパスワードでログインする。（機能一覧F-01）

**画面の絵**

```
[備品管理]
ログイン
  メールアドレス   [                    ]
  パスワード       [                    ] (目のマーク：押すと文字を表示)
  [ ] ログインしたままにする（60日間）
  [        ログイン        ]
  パスワードを忘れた方はこちら
  ※5回続けて間違えると、パスワードの再設定が必要になります
```

**入力項目**

| 項目 | 必須 | チェック | メッセージ |
|---|---|---|---|
| メールアドレス | ○ | 空でない。254文字まで。メールアドレスの形 | 「メールアドレスを入力してください」「メールアドレスの形が正しくありません」 |
| パスワード | ○ | 空でない | 「パスワードを入力してください」 |
| ログインしたままにする | | ― | ― |

パスワードの文字数などの決まりは、パスワードを決める画面（S-03・S-04）で設計する。ログイン画面では「空でないこと」だけを確かめる。

**ボタン・リンクの動き**

| 操作 | 動き |
|---|---|
| ログイン | 正しければ、1.4で開こうとしていた画面、なければ最初の画面（F-01）に移る。「ログインしたままにする」にチェックがあれば、60日間ログインしたままにする |
| パスワードを忘れた方はこちら | S-02に移る |

**ログインできないとき**

| 場合 | 動き |
|---|---|
| メールアドレスかパスワードが違う | 「メールアドレスまたはパスワードが違います」と出す。どちらが違うかは言わない（他人が登録の有無を調べられないように） |
| 削除されたユーザ | 上と同じメッセージ |
| 同じメールアドレスで5回続けて失敗した | そのユーザをロックする（2.1）。画面のメッセージは上と同じ |
| ロック中のユーザ | 正しいパスワードでもログインできない。画面のメッセージは上と同じ |

**その他**：ログインしている人がS-01を開いたときは、最初の画面に移る。

### 2.1 アカウントロック（Q1の回答）

1. 同じメールアドレスで、5回続けてパスワードを間違えたら、そのユーザをロックする（ログインできなくする）。時間がたっても自動では解除しない。
2. ロックを解除するには、パスワード再設定（S-02・S-03）で新しいパスワードを決める必要がある。新しいパスワードを決めた時点でロックを解除し、失敗の回数も0に戻す。
3. ロックしたら、本人にSlackのDMで「続けて間違えたためロックした」ことと、パスワード設定用のリンクを送る（9章の③）。本人が気づき、すぐ再設定できるようにするため。
4. 画面のメッセージは、ロックしたときも、ロック中も、通常の失敗と同じにする。画面にロックと出すと、他人に「このメールアドレスは登録されている」と分かってしまうため。代わりに、ログイン画面に「5回続けて間違えると、パスワードの再設定が必要になります」と常に表示しておく。
5. 失敗の回数は、ログインに成功したら0に戻す。登録されていないメールアドレスでの失敗は、数えない（ロックする相手がいないため）。
6. ロックしても、すでに「ログインしたままにする」でログインしている端末はそのまま使える。パスワードを再設定した時点で、すべての端末のログインが切れる（機能一覧6章の8）。

**注意**：他人が、ある人のメールアドレスで5回わざと間違えれば、その人をロックできてしまう。この場合でも、本人はSlackのDMのリンクからパスワードを再設定すれば元どおり使える。

## 3. S-05 自分の備品

**目的**：自分が借りている備品を見て、確認・返却をする。一般社員がいちばんよく使う画面。（機能一覧F-07・F-19）

**画面の絵**

```
[≡] [備品管理]                    山田 太郎
自分の備品
┃ 今月まだ確認していない備品が 1件 あります。
┃ 11/25（水）9:00 までに確認してください。
[ まとめて確認した（1件） ]

 ─────────────────────────
 A001  PC                  [未確認]
 Lenovo ThinkPad X1
 貸出日 2026/10/01  返却予定日 ―
 最終確認日 2026/10/20
 [ 確認した ]  [ 返す ]
 ─────────────────────────
 E012  モニター          [確認済み]
 EIZO FlexScan EV2485
 貸出日 2026/11/02  返却予定日 2026/11/30
 最終確認日 2026/11/02
 [ 確認済み ]  [ 返す ]
 ─────────────────────────
[ ＋ 備品を借りる ]
```

**表示する項目（備品1件ごと）**

| 項目 | 内容 |
|---|---|
| 管理番号・種別 | 例：A001　PC |
| メーカー・モデル | 例：Lenovo ThinkPad X1 |
| 貸出日・返却予定日 | 返却予定日を過ぎていたら、返却予定日を赤字にする |
| 最終確認日 | |
| 確認の状態 | 今月確認済みなら「確認済み」（緑）、そうでなければ「未確認」（黄）。黄は今のExcelの色分けに合わせた |

**並び順**：未確認の備品を上にし、その中は貸出日の古い順。

**上部の案内**

| 状態 | 表示 |
|---|---|
| 未確認の備品がある | 「今月まだ確認していない備品が N件 あります。○/○（曜）9:00 までに確認してください。」日付は今月の催促日（25日。土日祝日なら前の平日） |
| 今月の催促日を過ぎても未確認がある | 「今月まだ確認していない備品が N件 あります。確認してください。」 |
| すべて確認済み | 「今月の確認はすべて済んでいます。」 |
| 借りている備品がない | 一覧の代わりに「借りている備品はありません。」と「備品を借りる」ボタンだけを出す |

**ボタンの動き**

| 操作 | 動き |
|---|---|
| 確認した | 押すと、その備品の最終確認日をその日の日付にする（確認のダイアログは出さない）。完了メッセージ「確認しました（A001）」。今月確認済みの備品では、「確認済み」と表示して押せなくする |
| まとめて確認した（N件） | 未確認の備品が1件以上あるときだけ出す。確認のダイアログ「N件の備品を確認済みにします。手元にあることを確かめましたか？」で「確認した」を押すと、未確認の備品すべての最終確認日をその日の日付にする |
| 返す | 「返す」のダイアログを開く（下の表） |
| ＋ 備品を借りる | S-06に移る |

**「返す」のダイアログ**

| 項目 | 必須 | チェック | メッセージ |
|---|---|---|---|
| 返す備品 | ― | 表示のみ（管理番号・種別・メーカー・モデル） | ― |
| 返却日 | ― | 表示のみ（その日の日付） | ― |
| メモ | | 200文字まで | 「メモは200文字以内で入力してください」 |

「返す」を押すと返却を登録し、ダイアログを閉じて一覧から消す。完了メッセージ「返却しました（A001）」。

**操作できなかったとき**

| 場合 | メッセージ |
|---|---|
| 返そうとした備品が、すでに返却済み（別の端末で返した、総務が返却を登録した、など） | 「この備品はすでに返却されています」と出し、一覧を最新にする |

## 4. S-06 備品を借りる

**目的**：保管中の備品を探して借りる。（機能一覧F-18）

**画面の絵**

```
[≡] [備品管理]                    山田 太郎
< 自分の備品に戻る
備品を借りる
  [ 管理番号・メーカー・モデルで探す       ]
  種別 [ すべて ▼ ]
  12件
 ─────────────────────────
 A003  PC
 Lenovo ThinkPad X1
 [ 借りる ]
 ─────────────────────────
 E015  モニター
 EIZO FlexScan EV2485　24.1インチ / 1920×1200 / 昇降あり / ピボットあり
 [ 借りる ]
 ─────────────────────────
 [ さらに表示 ]
```

**探す条件**

| 項目 | 内容 |
|---|---|
| キーワード | 管理番号・メーカー・モデルのどれかに含まれていれば表示する。入力するたびに絞り込む |
| 種別 | 「すべて」と、登録されている種別から選ぶ |

**表示する備品**：管理状態が「管理中」で、貸出状態が「保管中」の備品だけ（機能一覧5章の1）。管理番号の順に20件ずつ表示し、「さらに表示」で続きを出す。

**表示する項目（備品1件ごと）**

| 項目 | 内容 |
|---|---|
| 管理番号・種別 | |
| メーカー・モデル | |
| 仕様 | サイズ・解像度・昇降・ピボットのうち、値が入っている項目だけを「 / 」でつないで表示する |

**「借りる」を押したときのダイアログ**

| 項目 | 必須 | チェック | メッセージ |
|---|---|---|---|
| 借りる備品 | ― | 表示のみ（管理番号・種別・メーカー・モデル） | ― |
| 貸出日 | ― | 表示のみ（その日の日付） | ― |
| 返却予定日 | | 日付の形。今日以降 | 「返却予定日は今日以降の日付を入力してください」 |

ダイアログの「借りる」を押すと貸出を登録し、S-05に移る。完了メッセージ「借りました（A003）」。貸出を登録した日は、その備品の最終確認日にもなる（機能一覧5章の6）ので、借りた備品は「確認済み」で表示される。

**操作できなかったとき**

| 場合 | メッセージ |
|---|---|
| 一覧を開いてから借りるまでの間に、ほかの人が先に借りた | 「この備品はすでに貸し出されています」と出し、一覧を最新にする |
| 借りられる備品がない | 一覧の代わりに「借りられる備品がありません。」と出す |
| 条件に合う備品がない | 「条件に合う備品がありません。」と出す |

## 5. S-02 パスワード再設定の依頼

**目的**：パスワードを忘れたときや、ロックされたときに、パスワード設定用のリンクをSlackのDMで受け取る。（機能一覧F-03）

**画面の絵**

```
[備品管理]
パスワードの再設定
  登録しているメールアドレスを入力してください。
  パスワードを設定するためのリンクを、SlackのDMでお送りします。
  メールアドレス   [                    ]
  [        送信        ]
  ログイン画面に戻る
```

**入力項目**

| 項目 | 必須 | チェック | メッセージ |
|---|---|---|---|
| メールアドレス | ○ | 空でない。254文字まで。メールアドレスの形 | 「メールアドレスを入力してください」「メールアドレスの形が正しくありません」 |

**ボタンの動き**

| 操作 | 動き |
|---|---|
| 送信 | 登録されているメールアドレスなら、そのメールアドレスでSlackのユーザーを探し、パスワード設定用のリンクをDMで送る（文面は9章の①）。どの場合も、画面には「登録されているメールアドレスであれば、SlackのDMでパスワード設定用のリンクを送りました。届かない場合は、総務に連絡してください。」とだけ出す |
| ログイン画面に戻る | S-01に移る |

**メッセージを変えない場合**：登録されていない、削除されたユーザ、同じメールアドレスへの依頼が5分以内（機能一覧6章の6。このときはDMを送らない）、Slackのユーザーが見つからない・DMを送れなかった（このときは、送れなかったことをシステムの記録（ログ）に残す）。どれも、他人に登録の有無を知らせないため、上と同じメッセージを出す。

**リンクの扱い**：新しいリンクを送ったら、それより前に送ったリンクは使えなくする。

## 6. S-03 パスワード設定

**目的**：SlackのDMのリンクから開き、新しいパスワードを決める。パスワード再設定と、ユーザ登録後の最初のパスワード設定の両方で使う。（機能一覧F-03・F-13）

**画面の絵**

```
[備品管理]
パスワードの再設定        ← ユーザ登録のリンクから開いたときは「パスワードの設定」
  yamada@example.com      ← 対象のメールアドレス（表示のみ）
  新しいパスワード       [                    ] (目のマーク)
  新しいパスワード（確認）[                    ] (目のマーク)
  ・8文字以上、64文字以内
  ・使える文字：半角の英字・数字・記号・スペース
  [        設定する        ]
```

**開いたときの確かめ**

| 場合 | 動き |
|---|---|
| リンクが正しく、有効期限内で、まだ使っていない | 入力欄を表示する |
| リンクが正しくない、期限切れ、使用済み、より新しいリンクが送られている | 入力欄の代わりに「このリンクは使えません。有効期限が切れたか、すでに使われています。」と「パスワード再設定の依頼へ」（S-02へのリンク）を出す |

**入力項目**

| 項目 | 必須 | チェック | メッセージ |
|---|---|---|---|
| 新しいパスワード | ○ | 8章の決まり | 8章のメッセージ |
| 新しいパスワード（確認） | ○ | 新しいパスワードと同じ | 「確認用のパスワードが一致しません」 |

入力中にも、文字数が足りているかどうかを決まりの横に表示する（例：「8文字以上」の前に✓を付ける）。

**ボタンの動き**

「設定する」を押し、正しければ次をまとめて行い、S-01に移る。完了メッセージ「パスワードを設定しました。新しいパスワードでログインしてください。」（自動ではログインさせない。機能一覧6章の8）

1. パスワードを新しいものにする。
2. このリンクを使用済みにする。
3. アカウントロックを解除し、ログインの失敗回数を0に戻す（2.1の2）。
4. すべての端末のログインと「ログインしたままにする」を切る。
5. パスワードが変わったことをSlackのDMで知らせる（9章の④）。ユーザ登録後の最初の設定のときは送らない。

## 7. S-04 パスワード変更

**目的**：ログイン中に、自分のパスワードを変える。（機能一覧F-04）

**画面の絵**

```
[≡] [備品管理]                    山田 太郎
パスワード変更
  現在のパスワード        [                    ] (目のマーク)
  新しいパスワード        [                    ] (目のマーク)
  新しいパスワード（確認）[                    ] (目のマーク)
  ・8文字以上、64文字以内
  ・使える文字：半角の英字・数字・記号・スペース
  [        変更する        ]
```

**入力項目**

| 項目 | 必須 | チェック | メッセージ |
|---|---|---|---|
| 現在のパスワード | ○ | 空でない。今のパスワードと同じ | 「現在のパスワードを入力してください」「現在のパスワードが違います」 |
| 新しいパスワード | ○ | 8章の決まり。現在のパスワードと違う | 8章のメッセージ。「現在と同じパスワードは使えません」 |
| 新しいパスワード（確認） | ○ | 新しいパスワードと同じ | 「確認用のパスワードが一致しません」 |

**ボタンの動き**

「変更する」を押し、正しければパスワードを変え、この画面を開く前の画面に戻る。完了メッセージ「パスワードを変更しました」。あわせて次を行う。

1. この端末以外のログインと、すべての「ログインしたままにする」を切る。この端末はログインしたままにする。
2. パスワードが変わったことをSlackのDMで知らせる（9章の④）。

**現在のパスワードを間違えたとき**：ログインの失敗と同じく回数を数える。5回続けて間違えたらロックし、この端末もログアウトさせる（ログインしたままのスマートフォンを他人に拾われ、パスワードを試されるのを防ぐため）。

## 8. パスワードの決まり

S-03・S-04で使う。米国国立標準技術研究所（NIST）が出しているパスワードの指針（SP 800-63B-4）に合わせる。

| 項目 | 決まり | 理由 |
|---|---|---|
| 長さ | 8文字以上、64文字以内（Q2の回答） | 最大は、NISTが64文字以上を許すよう勧めているため。最小について、NISTはパスワードだけでログインする場合は15文字以上、ほかの確認手段と組み合わせる場合は8文字以上としている。このシステムはパスワードだけでログインするが、使いやすさを優先して8文字にした。よく使われるパスワードの照らし合わせと、アカウントロック（2.1）で補う |
| 使える文字 | 半角の英字・数字・記号・スペース | パスワードの保存に使う仕組み（bcrypt。Spring Securityの標準）は、72バイトまでしか扱えない。日本語は1文字で3バイトになるため、半角だけにして64文字以内なら必ず収まる |
| 文字の種類の組み合わせ | 求めない（「大文字・数字・記号を必ず入れる」などはしない） | NISTが、こうした決まりを課してはならないとしているため。覚えにくくなるだけで、強さにつながりにくい |
| よく使われるパスワード | よく使われるパスワードの一覧と照らし合わせ、一致したら使えなくする（大文字・小文字は区別せずに比べる）。メールアドレスやシステム名（「備品管理」「equipment」など）と同じものも使えなくする | NISTが照らし合わせを求めているため。一覧は、SecLists（MITライセンスで公開されているリスト集）の「10k-most-common.txt」（よく使われるパスワード1万件）を使い、ファイルとしてシステムに持たせる。外部のサービスには問い合わせない |
| 定期的な変更 | 求めない | NISTが、定期的な変更を求めてはならないとしているため |
| 貼り付け・パスワード管理ツール | 使えるようにする（貼り付けを禁止しない。ブラウザやスマートフォンの自動入力が働くようにする） | NISTが求めているため。長いパスワードを手で打たずに済む |
| 入力中の表示 | 目のマークで、入力した文字を表示できるようにする | NISTが勧めているため。スマートフォンでの打ち間違いを防ぐ |

**メッセージ**

| 場合 | メッセージ |
|---|---|
| 空 | 「新しいパスワードを入力してください」 |
| 短い | 「パスワードは8文字以上で入力してください」 |
| 長い | 「パスワードは64文字以内で入力してください」 |
| 使えない文字がある | 「パスワードに使えるのは、半角の英字・数字・記号・スペースです」 |
| よく使われるパスワードなど | 「このパスワードはよく使われているため、使えません。別のパスワードにしてください」 |

**開発のときの注意**：Spring Securityには、72文字を超えるパスワードが正しくチェックされない不具合（CVE-2025-22228）があり、6.4.4・6.3.8で直っている。直った版以降を使い、そのうえで上の64文字の上限も入れる。

## 9. SlackのDMの文面

## 13. S-10 貸出履歴

## 14. S-11 最終確認日の一括更新

**目的**：総務が棚卸で確かめた備品の最終確認日を、CSVでまとめて更新する。（機能一覧F-08・F-09）

PCで使う前提。画面は上から「1. テンプレートをダウンロード」「2. 確認日を入れたファイルをアップロード」「3. 結果」の順に並べる。

**1. テンプレートのダウンロード**

「テンプレートをダウンロード」を押すと、管理中・保管中の備品を管理番号の順に並べたCSVを出す。ファイル名は「確認用テンプレート_20261102.csv」の形（日付はダウンロードした日）。Excelで開いても文字化けしない形で出す。

| 列 | 内容 | 総務が書き込むか |
|---|---|---|
| 管理番号 | 備品の管理番号 | 書き換えない |
| 種別 | 参考 | 書き換えない |
| メーカー | 参考 | 書き換えない |
| モデル | 参考 | 書き換えない |
| 前回の最終確認日 | 参考 | 書き換えない |
| 確認日 | 空で出す | 確かめた備品の行に、確かめた日を書く |

**2. アップロード**

| 項目 | チェック | メッセージ |
|---|---|---|
| ファイル | 必須。拡張子が .csv。1MBまで。1行目がテンプレートと同じ列名 | 「ファイルを選んでください」「CSVファイルを選んでください」「ファイルが大きすぎます（1MBまで）」「テンプレートの形と違います。テンプレートをダウンロードして使ってください」 |

文字コードは、UTF-8・Shift_JISのどちらでも受け付ける（Excelの保存の形式による。機能一覧10章）。日付は「2026/11/02」「2026/11/2」「2026-11-02」の形を受け付ける。

**行ごとのチェック**

| 場合 | 扱い |
|---|---|
| 確認日が空 | 更新しない（エラーにもしない） |
| 管理番号の備品がない | エラー「管理番号が見つかりません」 |
| 廃棄した備品 | エラー「廃棄した備品です」 |
| 不明の備品 | エラー「不明の備品です。見つかった場合は、備品の編集で管理状態を管理中に戻してください」 |
| 確認日が日付の形でない | エラー「確認日の形が正しくありません（例：2026/11/02）」 |
| 確認日が未来 | エラー「確認日に未来の日付は入れられません」 |
| 同じ管理番号が2行以上ある | エラー「同じ管理番号が複数の行にあります」 |
| 確認日が今の最終確認日より古い | 更新しない（エラーにもしない。社員がそのあとで確認していた場合などに、日付が戻らないようにするため） |

1行でもエラーがあれば、何も更新しない（機能一覧F-09）。

**3. 結果**

| 場合 | 表示 |
|---|---|
| エラーなし | 「N件の最終確認日を更新しました。」あわせて、確認日が空だった件数と、古い日付だったため更新しなかった件数を出す |
| エラーあり | 「エラーがあったため、更新していません。直してからもう一度アップロードしてください。」と、エラーの一覧（行番号・管理番号・理由）を出す |

## 15. S-12 催促履歴

**目的**：Slackでの催促（機能一覧F-10）を、いつ・だれに送ったか、送れなかったかを見る。（機能一覧F-11）

**画面の上部**：直近の催促の結果をまとめて出す。例：「2026/11/25（水）9:00　送った人 12人（成功 11人・失敗 1人）」。失敗がある場合は赤字にする。

**探す条件**：送った日（期間）、結果（すべて／成功／失敗）、宛先の氏名。

**表示する列**：送った日時、宛先（氏名）、対象の備品（管理番号を並べる）、結果（成功／失敗）、失敗の理由。送った日時の新しい順。50件ずつ。

**失敗の理由の例**：「Slackのユーザーが見つかりません（メールアドレスがSlackと違う可能性があります）」「Slackへの送信に失敗しました」。

失敗した人に、この画面から送り直す仕組みは作らない。総務が本人に直接知らせ、必要ならS-15でメールアドレスを直す。

## 16. S-13 種別管理

**目的**：備品の種別を見る・追加する・変える・消す。（機能一覧F-21）

**表示する列**：名前、頭文字、使っている備品の数（削除されていない備品）、操作。頭文字の順に並べ、頭文字がないものは後ろに名前の順で並べる。

**追加・変更のダイアログ**

| 項目 | 必須 | チェック | メッセージ |
|---|---|---|---|
| 名前 | ○ | 20文字まで。ほかの種別と重複しない | 「名前を入力してください」「名前は20文字以内で入力してください」「この名前はすでに使われています」 |
| 頭文字 | | 半角の英字1文字（小文字は大文字に直す）。ほかの種別と重複しない | 「頭文字は英字1文字で入力してください」「この頭文字はすでに使われています」 |

**ボタンの動き**

| 操作 | 動き |
|---|---|
| 追加（一覧の上） | ダイアログ「種別の追加」を、入力欄を空にして開く。「追加する」を押すと、正しければ追加し、ダイアログを閉じて「追加しました（PC）」と出す |
| 変更（各行） | ダイアログ「種別の変更」を、今の名前と頭文字を入れて開く。「保存する」を押すと、正しければ保存し、ダイアログを閉じて「保存しました（PC）」と出す |
| 削除（各行） | 確認のダイアログ「PCを削除します。」を出し、「削除する」を押すと削除して「削除しました（PC）」と出す |
| キャンセル（ダイアログ） | 入力を捨てて、ダイアログを閉じる（1.3） |

（ ）と「PCを削除します。」の「PC」には、その種別の名前（変更のときは保存したあとの名前）が入る。

**削除**：使っている備品が1つでもあれば「削除」を押せなくし、その行に「この種別の備品があるため削除できません」と出す（いつも表示する）。なければ、確認のダイアログのあとで削除する。

**ほかの人が先に保存していたとき**：変更のダイアログを開いてから保存するまでの間に、ほかの人が同じ種別を保存していたら、上書きせずに「ほかの人が先にこの種別を更新しました。画面を開き直して、最新の内容を確かめてください。」と出す（S-09と同じ考え方）。

## 17. S-14 ユーザ一覧

**目的**：ユーザを探し、登録・編集・削除の入口にする。（機能一覧F-12・F-13）

**探す条件**：氏名・メールアドレス（含んでいれば表示）、権限、ロック中だけ。

**表示する列**：氏名、メールアドレス、権限、借りている備品の数、状態（ロック中なら「ロック中」と表示）、操作（編集・削除）。氏名の順。50件ずつ。

**削除**（「ユーザを削除する」を持つ人にだけ出す）：確認のダイアログ「○○さんを削除します。削除すると、この人はログインできなくなります。」のあとで削除する（論理削除）。次の場合は削除できない。

| 場合 | メッセージ |
|---|---|
| 借りている備品がある | 「借りている備品があるため削除できません。先に返却を登録してください」 |
| 自分自身 | 「自分自身は削除できません」 |
| 「権限を管理する」を持つ人がいなくなる | 「権限を管理できる人がいなくなるため削除できません」 |

## 18. S-15 ユーザ登録・編集

**目的**：ユーザを登録する。登録したユーザの情報を変える。（機能一覧F-13）

**入力項目**

| 項目 | 必須 | チェック | メッセージ |
|---|---|---|---|
| 氏名 | ○ | 50文字まで | 「氏名を入力してください」「氏名は50文字以内で入力してください」 |
| メールアドレス | ○ | 254文字まで。メールアドレスの形。ほかのユーザと重複しない（削除済みのユーザのアドレスは使い直せる） | 「メールアドレスを入力してください」「メールアドレスの形が正しくありません」「このメールアドレスはすでに使われています」 |
| 権限 | ○ | 登録されている権限から選ぶ。「権限を管理する」を持たない人には選べない形で表示する（登録のときは一般社員になる。機能一覧8章） | 「権限を選んでください」 |

メールアドレスは、ログインと、SlackのDMの宛先探しに使う。Slackに登録しているメールアドレスと同じものを入れるよう、入力欄の下に書いておく。

**ボタンの動き**

| 操作 | 動き |
|---|---|
| 登録する | 登録し、パスワード設定用のリンクをSlackのDMで送り（9章の②）、S-14に移る。Slackのユーザーが見つからず送れなかったときは、「登録しましたが、SlackのDMを送れませんでした。メールアドレスがSlackと同じか確かめてください。」と出す（総務向けの画面なので、送れなかったことをそのまま知らせる） |
| 保存する | 保存し、S-14に移る |
| パスワード設定のリンクを送る（編集のときだけ） | 確認のダイアログのあと、本人にパスワード設定用のリンクを送る（9章の①と同じ文面）。登録時のリンクの期限が切れた人や、ロックされた人を手伝うときに使う。今のパスワードは、本人が新しいパスワードを決めるまで変わらない |
| キャンセル | S-09と同じ |

**ほかの人が先に保存していたとき**：S-09と同じ扱い。

## 19. S-16 権限一覧

**目的**：権限と、その中身を見る。（機能一覧F-14）

**表示する列**：権限の名前、含んでいる権限項目（項目名を並べる）、割り当てている人数、操作（編集）。「新規登録」と「編集」は、「権限を管理する」を持つ人にだけ出す。

## 20. S-17 権限登録・編集

**目的**：権限を作る・変える・消す。（機能一覧F-15）

**入力項目**

| 項目 | 必須 | チェック | メッセージ |
|---|---|---|---|
| 権限の名前 | ○ | 30文字まで。ほかの権限と重複しない | 「権限の名前を入力してください」「この名前はすでに使われています」 |
| 権限項目 | ○ | 1つ以上にチェック。機能一覧8章の18項目を、区分（備品／貸出／確認／ユーザ・権限）ごとにまとめて並べ、それぞれに説明を付ける | 「権限項目を1つ以上選んでください」 |

**削除**（編集のときだけ出す）：次の場合は削除できない。

| 場合 | メッセージ |
|---|---|
| この権限を割り当てている人がいる | 「この権限を使っている人がいるため削除できません（N人）」 |
| 一般社員の権限 | 「一般社員の権限は削除できません」 |

**保存できない場合**：「権限を管理する」を外した結果、それを持つ人が0人になるとき。「権限を管理できる人がいなくなるため保存できません」と出す。

**変更が効くとき**：権限の変更は、その権限を持つ人の次の操作から効くようにする（ログインし直さなくてよい）。「ログインしたままにする」で60日間ログインしている人がいるため、次のログインまで待つと、権限を外しても長く使えてしまうため。

## 21. S-18 一括登録（移行）

**目的**：今のExcelから、ユーザ・備品・今貸出中の情報を移す。（機能一覧F-16）

PCで使う前提。「ユーザ」「備品」「今貸出中の情報」の3つに分け、この順に取り込む（貸出中の情報は、ユーザと備品がそろっていないと取り込めないため）。どれも、1行目を列名とするCSVで、1行でもエラーがあれば何も登録しない。結果の出し方はS-11と同じ。

**ユーザ**（「ユーザを登録する」が必要）

| 列 | 必須 | 内容 |
|---|---|---|
| 氏名 | ○ | S-15と同じチェック |
| メールアドレス | ○ | S-15と同じチェック。ファイルの中でも重複しない |
| 権限 | | 権限の名前。空なら一般社員。「権限を管理する」を持たない人が取り込む場合は、すべて一般社員になる |

一括登録したユーザにはDMを送らない。各自がログイン画面の「パスワードを忘れた方はこちら」から最初のパスワードを決める（機能一覧F-16）。

**備品**（「備品を登録する」が必要）

今のExcelの在庫シートの列（機能一覧13章）をそのまま使う。在庫シートは見出しが2段（「機材仕様」などのまとまりの行と、列名の行）なので、CSVにするときは上の段を消し、列名の行を1行目にする。「＃」の付いた列（＃貸出状態・＃借用者・＃履歴不備）はあってもよい（読み飛ばす）。

| 場合 | 扱い |
|---|---|
| 種別 | 管理番号の頭文字と、種別の頭文字を照らし合わせて決める。合う種別がなければエラー「管理番号の頭文字に合う種別がありません」 |
| すでに登録されている管理番号 | エラー（上書きはしない）「この管理番号はすでに登録されています」 |
| 管理状態 | 管理中・廃棄・不明のどれか。廃棄なら廃棄日が必須 |
| 昇降・ピボット | 「○」（記号の丸）・「〇」（漢数字のゼロ）・「◯」（大きな丸）は「あり」、「×」「✕」は「なし」、空欄は「未設定」として読む。それ以外はエラー「昇降（ピボット）は○か×で入力してください」。今のExcelでは、昇降に「○」、ピボットに「〇」と、見た目は同じでも違う文字が使われているため、どちらも受け付ける（Q5の回答） |
| サイズ・解像度 | 書いてあるとおりの文字で移す（例：「21インチ前後」「1920 × 1080」）。20文字まで |

**今貸出中の情報**（「貸出・返却を管理する」が必要）

今のExcelの貸出履歴シートのうち、返却日が空の行（今貸出中のもの）だけを残してCSVにする。

| 列 | 必須 | 内容 |
|---|---|---|
| 管理番号 | ○ | 登録済みで、管理中・保管中の備品 |
| 借用者 | ○ | 氏名。ユーザの氏名と照らし合わせる。見つからない・同じ氏名が複数いる場合はエラー |
| 貸出日 | ○ | 今日以前 |
| 返却予定日 | | 貸出日以降 |

ファイルの中で同じ管理番号が2行以上あればエラー「同じ管理番号が複数の行にあります（今のExcelの履歴不備の可能性があります）」。

## 22. S-19 エラー

**目的**：画面を表示できないときに、理由と次にすることを知らせる。

| 場合 | 表示 |
|---|---|
| 権限がない | 「このページを見る権限がありません。」 |
| ページが見つからない（削除された備品のページなど） | 「ページが見つかりません。」 |

どの場合も「最初の画面へ」のボタンを出す。ログインが切れていたときは、エラー画面ではなくS-01に移る（1.4）。不具合の詳しい内容（プログラムの中身など）は画面に出さず、システムの記録（ログ）に残す。
